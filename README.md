# Golden Compass Navigator

A web application prototype for investment workflows and market analysis, with portfolio views, charting, watchlists, order history, and account interfaces.

## Highlights

- Portfolio and market dashboards
- Interactive market charts
- Watchlists and price-monitoring interfaces
- Order history and brokerage-account views
- Investment and account workflows

## Technology

React 19 · TypeScript · TanStack Start · TanStack Router · Vite · Supabase · Drizzle ORM · PostgreSQL · Tailwind CSS

## Getting Started

Requirements: Node.js and npm.

```bash
git clone https://github.com/XTAsync/golden-compass-navigator.git
cd golden-compass-navigator
npm install
npm run dev
```

## Development

```bash
npm run build
npm run lint
npm run preview
```

Configure required backend and external-service settings locally before using connected features. Never commit secrets or private credentials.

## Project Status

A development prototype. Do not interpret interface components as proof of live market-data coverage, brokerage connectivity, or real-money trading availability.
